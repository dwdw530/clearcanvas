# 净界 ClearCanvas 功能设计

确认日期：2026-10-06。平台：Windows 10/11 x64。语言：简体中文。

本文同时包含目标规划与阶段设计，实际已实现功能及当前限制以 [README](../README.md) 为准。

## 产品定位

安装后直接打开的本地桌面软件，处理 PDF 与图片中的水印。
不需要终端、不需要用户配置 Python。本地模式不上传文档；实验性的单图云端 AI 候选需逐次授权上传及可能计费。
目标是可检查、可撤销、保留原件的处理流程，不承诺通用无损修复。

## 两条处理路径

### 独立 PDF 水印对象

用户定位区域后，识别独立文字、图像或带标记的内容对象，展示候选及作用范围，
确认后删除。区域定位不等于删除区域内全部内容。无法可靠区分时拒绝自动删除。
保留正文文字、页面尺寸、顺序、书签等既有结构，实际保留情况需要测试验证。
共享资源对象不能直接全局删除，否则会误伤其他页；跨页操作逐页检查。
遇到数字签名、交互表单或权限限制时，必须在处理前明确提示影响。

0.3.0 新增免框选入口：自动删除显式标记为 Watermark、且图形状态隔离的内容块，
包括嵌套 Form 内的同类内容及 Watermark 批注。用 pypdf 解析操作符，不使用字符串替换。
选定页使用新的内容流和 Form 资源引用，不改写其他页面共享的原对象。
无明确标记时不猜测对象身份，转入保守的图像识别路径；未识别时提示手动框选。

0.3.9 支持图形状态保存/恢复紧邻标记外侧的同类内容，仍要求完整隔离，
不删除会影响后续路径、颜色或正文状态的非隔离标记。

### 图片与扫描 PDF 修复

矩形、画笔和擦除工具共同生成选区蒙版，在选区内使用成熟图像修复算法。
支持多个选区、撤销重做、原图对比及参数调整，生成独立结果后才能导出。
选区外像素在无损输出时应保持不变；JPEG 重编码带来的变化必须明确区分。
文字被遮挡时不能把推测内容当原文，不自动补写正文。
扫描 PDF 只处理选中页面；重建处理页可能丢失文字层，必须由用户确认。

0.3.0 自动图像路径：使用 OpenCV 连通域与倾斜文本几何特征，识别浅色背景上的
浅灰倾斜文字水印，生成像素级蒙版；深色文字及边缘保护，选区外像素不变。
自动检测不承诺区分所有水印和浅灰倾斜正文，必须先检查原图/结果再导出。
复杂照片、深色/彩色/水平水印、小水印可能未命中；不静默转为整页涂抹。
PDF 自动批量逐页检测，异形页独立处理，未命中页保持原样并报告；
所选页均未命中时不生成伪成功文件。原件只读、取消和临时导出保护保持不变。
同页发现独立水印后只走对象删除，不隐式追加可能丢失文字层的图像修复。

0.3.9 照片路径在原尺寸上收紧已确认的纯色笔画，保留多色与半透明情况的保守蒙版。
宽笔画组合使用现成非 AI 实现：低纹理轮廓由 G'MIC 4.0.5 的多尺度边缘引导扩散延续，
局部纹理使用 PyPatchMatch 和 OpenCV 融合，均匀渐变使用调和插值。所有取样排除其他水印
与透明像素，最终严格按原蒙版合成。G'MIC 运行配置与临时图像隔离，子进程可取消并设超时；
处理时不下载组件、不读取自定义 G'MIC 脚本、不联网。
这些是受限的近似填补，不代表恢复了被不透明水印遮住的原始五官或文字。

## 可选云端 AI 图片候选

2026-10-25 增加实验性云端路径，并按用户明确指令升级、打包和安装为 0.4.0 候选。
完整规格以 [云端 AI 设计](cloud-ai-design.md) 为准；原两条本地路径的检测器和修复算法保持不变。

- 每次启动默认本地，PDF 强制本地，云端首版仅单张 JPG/JPEG/PNG，不支持 PDF 或批量。
- 原生设置对话框：HTTPS 地址、实际编辑端点、隐藏 Key、会话 Key/Windows 凭据管理器、
  默认示例模型与预设、可选蒙版、总超时；保存/取消与打开文件不联网。
- 图片接口测试仅上传程序生成图，需计费确认，与修复单飞；没有文档也可执行。
  默认数量及协议未知时，须先测试/核实；不自动增加数量参数或假称已验收。
- 本地自动识别/矩形蒙版 → 上下文单裁剪、等比补边请求计划 → 用户确认上传 →
  独立 QtNetwork 线程的一次编辑请求 → 串行本地解码、构图检查、蒙版内 RGB 合成。
- 返回不同尺寸或明显位移拒绝，证据不足需人工原始比例核对；确认前不生成可导出结果。
  PNG 蒙版外 RGBA 完全不变、alpha 保留；JPEG 全图重编码与降采样细节损失明确提示。
- 失败/取消保留原件与旧结果，无自动重试；导出既有 AI 图片只保存结果。
  结果来源/模型/域名按真实生成配置显示，切换模式或设置不丢结果，也不会重新请求。
- 凭据按 API 根隔离，不进入 QSettings、图像、结果、日志或安装包；错误不回显服务端文本。
  正常证书验证、拒绝重定向、有限响应缓冲、连接/总超时和所属线程取消。
- 2026-10-25 经用户分别确认，生成图一次及指定人像/彩色边角各一次真实请求均为 HTTP 200、
  返回 1 张 1536×1024；人像/边角已通过构图检查及原尺寸 PNG 导出，蒙版外 RGBA 与 alpha 不变。
  共三次，无自动重试，实际费用未知；结果与基线对比见 `artifacts/cloud-ai-quality-20261025/`。
  当前模型无法看图，五官/背景/边角纹理的人工画质验收未完成；其他预设/蒙版协议及干净 Windows 安装仍未验收。
  不默认重复调用，追加上传/计费与打包/安装/发布仍分别需要授权。

## 功能规格

| 模块 | 规格 |
| --- | --- |
| 导入 | 文件对话框、多文件拖入、重复路径去重、逐项报告无效文件 |
| 浏览 | 文件切换、PDF 翻页和页码跳转、缩放、适应窗口、原始比例、拖动画布 |
| 信息 | 文件名、路径、类型、文件大小、总页数、当前页尺寸 |
| 选区 | 矩形、画笔、擦除、多个区域、撤销重做 |
| 预览 | 原件与结果切换、并排对比；参数变化使旧结果失效 |
| PDF 范围 | 当前页、明确页码集合、全部页；检查异形页和页面方向 |
| 批量 | 多文件队列、单项状态、进度、取消、部分失败不阻断其他文件 |
| 导出 | 输出目录、另存文件名、重名确认、失败不留下伪成功文件 |
| 安全 | 原件只读、密码/会话 Key 仅在内存、无遥测、无静默联网；云端上传逐次确认 |
| 安装 | 独立安装包、可选快捷方式、卸载、不要求管理员安装运行库 |

跨页选区使用明确的页面坐标变换；尺寸或方向不同的页面不能直接复用像素坐标。
取消不删除原件；临时结果与原件分离。导出采用临时文件完成后再原子提交。
禁止使用白块覆盖冒充水印修复，也不把区域涂除冒充 PDF 对象识别。

## 界面

- 顶部：品牌、文件操作、缩放和视图控制；后续加入处理和导出命令。
- 左侧：文件列表；当前文件清晰高亮，长文件名省略显示，完整路径可查看。
- 中间：文档画布与当前页导航，是界面的主要空间。
- 右侧：文件信息；后续处理阶段切换到选区和处理参数。
- 底部：状态和进度。处理错误、取消与空状态有独立反馈。

视觉采用实用桌面工作台：中性灰白底色、深灰文字、青绿色主操作、少量琥珀色提示。
面板用分隔线而不是浮动卡片，圆角不超过 6px。使用 Lucide 图标与明确的悬浮提示。
中文使用 Windows 原生可读字体；键盘焦点可见；工具按钮尺寸固定，状态变化不跳动。
目标最小窗口 1000 x 680，检查 100%、150%、200% DPI；不以网页移动端尺寸约束原生桌面窗口。

## 技术边界

- Python + PySide6 Essentials 构建原生窗口与画布。
- pypdfium2 / PDFium 负责只读渲染；Pillow 负责图片解码与 EXIF 方向处理。
- PDFium 调用串行，UI 与后台工作分离；仅展示最新请求，防止快速切换串页。
- 图像修复和结构化 PDF 编辑分别在对应阶段验证库、许可和测试样本后接入。
- PyInstaller 先产出独立运行目录；安装器在第 6 阶段完成。
- 不使用 PyMuPDF 作为默认依赖，避免未确认发行方式前引入 AGPL 商业分发决策。

## 分阶段交付

| 阶段 | 内容 | 必须通过的验收 |
| --- | --- | --- |
| 1 | 桌面窗口、导入、图片/PDF 预览 | 中文与空格路径、EXIF、透明图、异形 PDF 页、密码、损坏文件、缩放翻页、快速切换、原件哈希不变 |
| 2 | 图片选区、修复、对比、导出 | 单图完整闭环、选区外保护、撤销重做、重名保护、无结果禁止导出 |
| 3 | PDF 独立对象识别与删除 | 正文与共享资源不被误伤、结构保留验证、不支持对象明确跳过 |
| 4 | 扫描 PDF、指定页码、跨页 | 页码解析、混合尺寸坐标、页面顺序与大小、未选页不变、文字层损失提示 |
| 5 | 批量与异常恢复 | 部分失败、任务取消、重复请求、大文件资源约束、临时文件清理 |
| 6 | 安装与发布 | 干净 Windows 环境离线启动、升级卸载、许可、快捷方式、DPI、签名状态说明 |

每个阶段先完成实现和自动化测试，再做窗口截图检查和实际启动测试。
第 1 阶段仅验证桌面基础，不宣称已经完成去水印功能。

## 暂不纳入

视频、Word、账号系统、云端 PDF/批量、OCR 重建文字层、任意背景的通用水印识别、
复杂内容的生成式复原、自动更新服务、商业数字签名证书。
