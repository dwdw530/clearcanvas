# 净界 ClearCanvas

面向 Windows 的 PDF、图片去水印工作台。本地模式不联网；新增可选、实验性的单张图片云端 AI 候选。原文件始终只读，结果另存。

0.4.3 是预发布版，包含原像素裁剪上传、按比例输出、严格对齐保护，以及源码运行组件提示修复；保留此前本地识别、范围编辑、局部合成与返回图留存。
此前生成图与两张指定图片的真实请求、构图检查和原尺寸导出已完成，但人工画质仍未验收。
打包、安装、提交或测试通过都不代表画质合格；本地 0.3.9 指定人像的鼻孔、鼻翼、唇线及自然度仍有缺陷。
旧 0.3.9 不包含云端候选，0.4.0 / 0.4.1 包含旧流程；没有集成本地 AI 模型。

0.4.3 包含 **2026-11-13 保真优先修订**。旧 0.4.2 安装包和免安装目录不包含这次修订，请通过新程序的版本号和上传尺寸说明区分；不会自动升级本机安装。

版本变更与验证记录见随包 [更新日志](CHANGELOG.md)。

安装包与版本说明见 [GitHub v0.4.3 预发布页](https://github.com/dwdw530/clearcanvas/releases/tag/v0.4.3)。新包构建后复用验证过的字节发布，旧包保留；画质仍需检查实际结果。

## 当前范围

0.4.1 保留以下本地能力，并提供下方可选云端候选：

- 一键去水印：不框选即可识别当前图片或 PDF 当前页，生成结果预览。
- PDF 优先删除有明确水印标记的独立内容及水印批注，保留正文、文字层及其他批注。
- 图片与扫描 PDF 自动识别浅色背景上的浅灰倾斜文字水印，只修复识别出的笔画像素。
- 照片支持部分高对比文字、重复水印和底部文字水印；修正中文断开笔画与底部位置误判。
- 对已识别出的浅灰底部文字行，使用局部颜色补齐低对比笔画，过滤不符合文字颜色的背景亮缝；彩色背景不强行套用同一颜色模型。
- 重复水印需匹配实际笔画形状；避免把店面亮块当成重复文字，或把浅色文字中的暗背景重复抹除。
- 支持将贴边裁切的重复文字与完整文字匹配，修正平铺水印因外框尺寸差异而漏检的问题。
- 按颜色与笔画形状识别彩色文字，覆盖不同色相和部分半透明水印；补齐旋转后只剩部分笔画的重复文字，并限制背景颜色误选。
- 对已确认的不透明彩色笔画按原尺寸收紧蒙版，保留旁边的鼻翼、唇线等原像素；多色与小字号分别校验，不把半透明水印强行当成纯色。
- 照片修复使用附近未被水印覆盖的小块纹理进行匹配填补，减轻平滑修复的字形暗影；无可靠纹理、区域过大或达到匹配预算时保留原有插值结果。
- 宽笔画复用 [PyPatchMatch](https://github.com/mauwii/PyPatchMatch) 的非 AI 纹理修复与 OpenCV 无缝融合；按局部纹理强度保留头发、背景纹理，平滑区域保留插值。其他水印与透明区域从取样背景中排除。
- 宽笔画跨越低纹理轮廓时，复用 [G'MIC 4.0.5](https://github.com/GreycLab/gmic/tree/v.4.0.5) 多尺度边缘引导扩散，减轻鼻唇附近的块状拼接；纹理区保留 PatchMatch，均匀渐变保留调和插值。全程非 AI、本地处理，组件随安装包提供。
- PDF 同时支持水印标记内部和紧邻外部的完整图形状态隔离块，保留正文、共享资源及未处理页。
- PDF / JPG / PNG 框选水印、多个选区、撤销选区、原图与结果对比。
- 手动选区使用 OpenCV Telea；自动文档修复使用局部纸张背景估计，仅替换识别出的水印笔画，避免附近正文颜色扩散。
- 图片按原尺寸导出 PNG 或 JPEG；PNG 选区外像素不变。
- PDF 可处理当前页、全部页或指定页码；未处理页保留。
- 多文件批量导出、进度、取消、部分失败报告及自动避让重名。
- Windows 安装向导、桌面及开始菜单快捷方式、卸载入口。
- 安装位置可选，默认沿用已有安装目录；卸载前检查净界是否运行，提示保存并退出后重试。

操作：打开文件，点击“一键去水印”，切换“原图/结果”检查，然后导出。
自动识别未命中时，可框选水印并点击“修复选区”。清空按钮可丢弃选区与结果。
PDF 先生成当前页预览，再选择右侧处理范围导出；自动模式会逐页重新识别，
支持不同尺寸、不同位置的水印。未可靠识别的页保留原样，并在导出后报告页码。
自动结果的批量导出对每个文件独立识别，支持混合 PDF、JPG、PNG；
从图片结果开始批量导出时处理 PDF 全部页，从 PDF 结果开始时使用所选页码范围。
手动框选结果仍按同类型、同尺寸的选区模板批量处理。

自动识别不是通用 AI：复杂照片、低对比、多色渐变或很小的水印仍可能无法识别，
会提示手动框选。纹理匹配仍可能产生局部拼接痕迹，不能保证找回原始细节。浅色倾斜正文也可能被误识别，必须检查预览；深色正文像素受到保护，
但与正文重叠的水印可能残留。复杂纹理和被遮挡的原文不能保证还原，不自动补写文字。
PDF 对象删除仅支持显式 Watermark 标记且图形状态独立的内容块、嵌套 Form 中的同类内容、
以及 Watermark 批注；无标记的内容不猜测删除，转而尝试像素识别。
PDF 若使用图像修复，处理页的文字层、链接和批注会移除，导出前有确认。
同页同时含独立水印与嵌入图片水印时，优先处理独立水印，不自动叠加图像修复。
加密、带表单或数字签名的 PDF 暂不支持修复；手动模式不强行套用异形页选区。

完整功能、处理边界及验收要求见 [功能设计](docs/product-design.md)。

## 云端 AI（0.4.3 预发布版，人工画质未验收）

**0.4.3 预发布版**：包含保真优先、范围编辑、严格对齐、合成预览及任务留图流程。旧 0.4.2 包继续保留，不自动安装或升级。

用户已选择保真优先：按标准协议计算尺寸，但不把本地通过当成中转兼容性保证。若中转不按请求尺寸返回，图片可以另存但不能合成；发布不放宽这一保护，也不代表五官画质已达标。

### 怎么操作

1. 打开原始 PNG/JPEG 图片，不要把缩小补边后的 `upload.png` 当原图反复处理。
2. 在「AI 接口设置…」填写 HTTPS 服务根或 `/v1` 根、API Key、模型，然后保存。默认示例为 `https://code1.newcli.com/v1`、`gpt-image-2`、`high / b64_json`；输出尺寸按修复区域比例计算，不再固定为横向画布。不推断服务方实际模型身份、价格或数据保留政策。
3. 主动选择「云端 AI」，点击「AI 去水印」，或先框选再点击「AI 修复选区」。本地模式主按钮显示「本地一键去水印」，不联网、不计费。
4. 第一步只检查**修复范围**：橙色表示允许修改的位置，不是去水印结果。可以补选、擦除、撤销和清空；没自动识别到时也可以直接画出水印。Ctrl + 滚轮缩放，选「拖动」查看细节。这一步不联网。
5. 第二步分别显示原图、原像素上传裁剪及请求返回的尺寸。上传图片不缩放、不补边；返回尺寸按 16 像素对齐，总像素介于 655,360 与 1,572,864 之间。只有点击「确认上传并生成（可能计费）」才提交一次请求；返回或取消不会上传。
6. 收到图后先检查位置对应，证据充分的小偏移可受限本地校正。尺寸不符合本次请求、明显构图变化、缺失内容或无法可靠确认对齐，都禁止合成；不确定状态不能通过点击确认绕过。安全返回图仍可查看和另存。
7. 只有对齐通过，或受限校正重新通过检查并经用户确认后，才生成原图局部合成预览。分别检查水印、鼻翼/唇线、头发及接缝；右侧才是导出结果。原 alpha 与范围外 RGBA 不变，不整张采用模型返回图，也不保证被遮挡五官真实还原。
8. 满意后点击「使用此结果（不联网）」，再导出 PNG/JPEG。可合成的已收图允许离线调整范围，不会再次请求 API；不能合成的图只提供查看与另存。新增范围不得超出已上传区域或校正后的可用内容。

### 付费、保留和保护规则

- 「重新生成 AI（可能计费）」是新请求，仍要确认范围与上传费用；新图取得后替换当前保留图，旧图需要时请先另存。失败不自动重试，不换模型、不拆成多次请求、不追加候选。
- 当前仅保留最近一次成功安全解码的返回图和该任务的原图/范围，不自动写磁盘。关闭核对或取消离线调整不会释放；另存、导出、切换设置和查看均不联网。退出前未另存会询问保存或明确放弃。
- 「另存完整 AI 返回图…」保存原始返回画布 PNG，不是原尺寸的局部合成结果；去除元数据、原子写入并禁止覆盖原件或其文件别名。它未经画质验收。
- 不提供让用户猜测的「提交蒙版」开关。中转的 `mask` 能力尚未确认，因此不发送；**不提交区域文件，不等于关闭本地修复范围保护**。旧 `send_mask` 和固定 `size` 设置不再控制请求，保存设置时清理。
- 「测试图片接口（可能计费）」是可选的，实际上传程序生成图，需单独确认；只验证本次测试图的响应尺寸及解码，不证明所有比例兼容或去水印效果。无需每次使用前重新付费测试。
- 每次启动默认本地；保存设置不会自动选择云端。Key 默认隐藏，不勾选安全记住时只在本次运行内存中使用；勾选后按服务根隔离保存到 Windows 凭据管理器，不写普通配置、结果或日志。
- 上传保留原像素不等于返回保留全部细节：返回分辨率可能较低，原尺寸导出不能恢复已丢失的细节。原像素上传也可能增加输入费用；输出像素预算不增加不代表费用不变。上传裁剪 PNG 超过 32 MiB 或比例超出 1:3 至 3:1 时停止，不偷偷降质或追加请求。PNG 范围外像素保持不变；JPEG 重编码可能改变全图像素。
- 云端仅支持单张 PNG/JPEG，不支持 PDF 或批量；打开 PDF 强制本地。总超时默认 300 秒（60–600 可调）、连接阶段 15 秒；取消只能停止本机等待，服务端可能继续生成，费用不保证撤销。
- 本轮离线验证为 **160 项通过**，已检查实际 Windows Qt 上传、拒绝、不确定及合成对话框。指定人像的上传为 **3080×1600**，与原图像素一致；请求返回为 **1728×896**，尚未向中转发送。程序生成图的原尺寸导出、范围外像素及已知修复真值验证通过，不代表真实照片画质达标。


**实际验证**：2026-10-25 经用户分别确认，完成生成图一次及指定人像/彩色边角各一次请求，
均使用当时的固定预设、不发 `mask` 或 `n`，HTTP 200，每次返回 1 张 1536×1024 图片，没有自动重试。这些历史请求不能作为当前按比例尺寸和原像素上传的兼容性证明。

## 开发

需要 Python 3.12 和 [uv](https://docs.astral.sh/uv/)。在项目根目录执行：

```powershell
uv sync --locked
uv run python tools/prepare_gmic.py
uv run python -m clearcanvas
uv run pytest
uv run ruff check .
```
源码版能打开窗口，不代表本地修复组件已就绪。首次运行或清理 `artifacts/build/` 后，必须先执行 `tools/prepare_gmic.py`；不能只启动 Python 主程序。已有 `.venv` 时，在项目根目录执行：

```powershell
& .\.venv\Scripts\python.exe tools/prepare_gmic.py
if ($LASTEXITCODE -ne 0) { throw "轮廓修复组件准备失败，未启动程序。" }
& .\.venv\Scripts\python.exe -m clearcanvas
```

准备步骤会校验或下载固定版本 G'MIC，不调用图片 API；实际本地修复不联网。组件缺失时源码版提示准备命令，安装版才提示重新安装。测试源码交付时，应同时验证需要原生组件的本地图片路径，不能用 API 专项通过代替。


运行目录可以与源码目录不同。中文文件名、含空格路径均受支持。
本地模式与本地文档处理不发起网络请求；云端 AI 仅在用户逐次确认图片接口测试或修复后联网。
开发依赖和构建准备的下载另行进行，不是产品处理的后台行为。
开发环境首次运行 `prepare_gmic.py` 下载固定版本并验证 SHA256；后续复用校验通过的缓存。
G'MIC 使用隔离的临时配置目录，不加载用户脚本或联网更新。取消会终止本次轮廓修复子进程，
单次受限区域计算超过 30 秒时明确报错，不以旧结果冒充成功；临时图像处理后清理。

测试会自行生成基础图片和 PDF。依赖本机字体、下载样本或 Windows 构建产物的专项测试，
在条件不满足时跳过；完整 Windows 安装验收需额外运行构建流程。

虚拟环境、缓存、`build/`、`dist/`、`artifacts/`、本地会话存档和机器验收记录不进入 Git。
安装包如需分发，可单独上传 GitHub Releases，不放入源码提交。
探针生成的 `-changed.png` 是洋红色修改区域高亮图，不是输入原图；`-result.png` 才是处理结果。

## 构建

在 Windows 上构建。可使用已安装的 NSIS 3.11，或按下面命令准备校验过的便携版本。

```powershell
uv run python tools/prepare_build.py
uv run pyinstaller --noconfirm clearcanvas.spec
uv run python tools/prepare_installer.py
uv run python tools/prepare_nsis.py
& artifacts/build/nsis/nsis-3.11/makensis.exe /INPUTCHARSET UTF8 /V2 packaging/installer.nsi
```

构建产物为 `dist/ClearCanvas/ClearCanvas.exe` 及同目录运行库。
不能只拷贝 EXE，整个 ClearCanvas 目录需要一起分发。
安装包为 `dist/ClearCanvas-0.4.3-Setup.exe`，当前用户安装，不要求管理员权限。
安装时可选择有写入权限的目录。安装及卸载均会检查净界进程；运行中可退出软件后重试，
或取消操作。静默模式遇到运行中的净界会停止并返回退出码 2，不强制结束进程。
也可使用 NSIS 官方便携包，以 `makensis.exe` 的完整路径替代上述命令；编译器不随源码提交。

需要保留旧运行目录时，可指定独立输出，并把相同目录传给安装器清单与 NSIS：


## 数据与资源边界

- 只接受 PDF、JPG、JPEG、PNG，不遍历导入的目录。
- 原文件只读，不建立最近文件记录，不记录文档内容或密码。
- 密码仅在本次运行内存中保留，移除对应文件或退出时清除。
- 单文件上限 1 GiB；图片上限 4000 万像素；预览长边上限 3200 像素。
- 单次选区上限为图像的 30% 且不超过 200 万像素，过大时需分次处理。
- PDF 处理页以最高 200 DPI 栅格化，复杂大文件的处理可能需要较长时间。
- 取消在处理步骤之间生效；未完成导出不会留下伪成功文件。
- 修复结果未导出时，切换文件、翻页或退出会提示确认。
- 缩放改变预览显示比例，不改变原件，也不代表输出质量。
- PDF 库调用串行执行；界面只接受最新预览请求的结果。
- 关闭程序时等待正在执行的受限预览任务结束，不强杀处理线程。
- 预览不执行 PDF 链接、脚本或外部跳转。暂不处理动画 PNG。

## 第三方组件

Qt / PySide6、PDFium / pypdfium2、Pillow、OpenCV、NumPy、pypdf 和 Lucide 的许可分别适用。
PyPatchMatch 使用 MIT 许可，Windows 组件自带的 OpenCV 及其他组件许可随安装包保留。
G'MIC CLI 以独立子进程调用，保留上游 Windows 发行包、CeCILL / CeCILL-C 许可与对应源码地址；
其 DLL 放在独立 `gmic` 目录，不混入 Qt 运行库。G'MIC 版本与下载校验值在适配模块中固定。
版本由 `uv.lock` 固定。分发前需要保留组件许可及 Qt 动态库替换能力；
商业发行、签名和完整合规审核不属于本阶段。

Lucide 图标取自 `lucide-static@0.468.0`，原始许可随资源保留。
Windows 开发环境固定使用独立 Python 3.12，避免与已有 Anaconda 运行库混用。
